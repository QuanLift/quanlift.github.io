# quanlift.github.io

Source of the QuanLift, Inc. website, served by GitHub Pages at https://quanlift.github.io.

- `index.html` is the whole site; there is no build step.
- Edit, commit to `main`, and GitHub Pages redeploys within a few minutes.
- The contact form posts to a Formspree endpoint; no email addresses are stored in this repository.
