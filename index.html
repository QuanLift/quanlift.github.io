Quantum programs you can trust, from the code you already have.

QuanLift translates existing optimization code into quantum programs and backs each translation with a machine-checked guarantee, so teams can try quantum hardware on their own problems without a quantum specialist and without a silently wrong answer.

Talk to us

Interest in quantum computing is broad. Adoption is shallow.

Organizations want to know whether quantum acceleration helps on their own optimization problems. Today that takes a specialist to reformulate the problem by hand, and specialists are scarce. The code that does get written can be wrong in ways nobody can see.

What we do

Give QuanLift ordinary Python optimization code. It returns a quantum program together with a machine-checked proof that the problem was encoded correctly for the problem family it recognized, and a check that the generated circuit matches that encoding. When it cannot give that guarantee, it declines and says why.

Your Python

Existing optimization code, as written. No annotations, no quantum knowledge.

→

QuanLift

Recognizes the problem, translates it, and checks the result against a formal certificate.

→

A certified program, or a refusal

A quantum program with its certificate and a report of what was checked, or a stated reason it was declined.

The library currently covers 24 problem families with machine-checked encoding proofs. Across all our test sets to date, the system has never produced an incorrect translation; what it cannot certify, it refuses.

An example

A maximum-cut function as a developer would write it, and the two kinds of answer QuanLift gives: a certified translation, and a refusal when a program is outside what it can certify.

# plain Python — no quantum code
def cut_value(part, G):
    return sum(w for (u, v, w) in G
               if part[u] != part[v])
# goal: maximize cut_value
